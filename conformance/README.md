# `conformance/`

Protocol conformance suites — the **I7** gate ("protocol conformance is a gate"). Governing RFCs:
**011-MCP-Conformance.md**, **012-A2A-Conformance.md**, **013-UI-and-Streaming-Surfaces.md**. Each
suite is tagged with the protocol revision it proves conformance against, per CONVENTIONS.md's
protocol code rules.
