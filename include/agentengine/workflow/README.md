# `agentengine::workflow`

L3 multi-agent orchestration: the executor/edge graph, fan-out/fan-in and switch/case patterns,
superstep execution, and checkpointing that make multi-agent structure explicit, typed, and
inspectable rather than emergent from agents calling each other. Governing RFC:
**014-Workflow-and-Orchestration.md**.

This directory currently declares shape only — see CLAUDE.md's `design -> red-team -> prove ->
judge` rule for anything contested, hot-path, or security-critical before real orchestration logic
lands here.
